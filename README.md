# GPT Astra Token HUD

ส่วนเสริม Chrome ที่แสดงหลอดงบโทเคนมุมขวาบนในหน้า ChatGPT อัปเดตระหว่างตอบ เมื่อแก้ข้อความ และเมื่อเปลี่ยนแชต

**หลอดนี้เป็นงบส่วนตัวแบบประมาณ ไม่ใช่โทเคนคงเหลือจริงของบัญชี ChatGPT/Codex** ระบบแชตไม่ได้เปิดเผยข้อมูลยอดนั้นให้ส่วนเสริมนี้อ่าน ไม่มีการตั้งค่าโควตาหรือขนาดบริบทของโมเดลให้อัตโนมัติ

## ติดตั้ง

1. แตกไฟล์ `gpt-astra-token-hud.zip` ที่สร้างไว้ใน `artifacts/`
2. เปิด `chrome://extensions` และเปิด **Developer mode**
3. กด **Load unpacked** เลือกโฟลเดอร์ `gpt-astra-token-hud` ที่แตกไฟล์แล้ว
4. โหลดหน้า ChatGPT ใหม่ กดปุ่มตั้งค่าบนหลอด แล้วใส่งบโทเคนส่วนตัวที่ต้องการใช้

หากยังไม่ได้สร้าง ZIP ให้ทำตามขั้นตอนพัฒนาด้านล่าง แล้วเลือกโฟลเดอร์ `dist` ในข้อ 3 แทน

## การนับ

นับข้อความของผู้ใช้และผู้ช่วยที่โหลดอยู่ในหน้าแชตด้วย tokenizer `o200k_base` รองรับภาษาไทย โค้ด และ emoji แล้วแสดง `งบที่ตั้งเอง − จำนวนโทเคนข้อความ` เป็นงบเหลือโดยประมาณ หากใช้เกินงบ หลอดจะเป็นสีแดงและแสดงเหลือ 0

นับใหม่จากข้อความปัจจุบันทุกครั้ง จึงไม่บวกซ้ำระหว่าง streaming หรือเมื่อแก้คำตอบ งบที่ตั้งไว้ใช้เป็นเพดานส่วนตัวร่วมกัน แต่จำนวนที่ใช้คำนวณแยกตามหน้าแชตที่เปิดอยู่ ไม่ใช่ยอดสะสมค่าใช้จ่าย API

ข้อความระบบ เครื่องมือ reasoning รูปภาพ ไฟล์แนบ และประวัติที่หน้าเว็บไม่ได้โหลดไม่อยู่ในยอดนี้ โมเดลอาจใช้ tokenizer ต่างกัน การย่อบริบทและขีดจำกัดตามเวลาของบัญชีวัดด้วยวิธีนี้ไม่ได้ หากข้อความเก่าถูกเอาออกจาก DOM ยอดที่นับได้อาจลดลง

รองรับหน้าแชต ChatGPT ที่มีโครงสร้างข้อความที่รู้จัก รวมถึงแชต Custom GPT ที่ใช้โครงสร้างเดียวกัน หน้าที่อ่านโครงสร้างข้อความไม่ได้ เช่นหน้า Codex บางหน้า จะแสดง **ยังไม่ทราบ** แทนตัวเลข หน้าเว็บจริงอาจเปลี่ยนโครงสร้างได้

## ข้อมูลส่วนตัว

ไม่มี API key ไม่มีการส่งข้อความออกไปยังเซิร์ฟเวอร์ อ่านข้อความเพื่อคำนวณภายในเบราว์เซอร์ และบันทึกเฉพาะงบที่ตั้งไว้ใน `chrome.storage.local` การนับทำใน service worker ของส่วนเสริมเพื่อไม่ให้หน้าจอค้าง การทำงานไม่แก้ไขคำสั่งหรือคำตอบของ GPT

## พัฒนาและทดสอบ

ต้องใช้ Node.js 20 ขึ้นไป การสร้าง ZIP ใช้ Python 3 และการทดสอบเบราว์เซอร์ใช้ Chromium ที่ติดตั้งในเครื่อง

```bash
cd /workspace/GPT-Astra
npm ci --cache /tmp/gpt-astra-npm-cache
npm run build
npm test
npm run test:browser
python3 scripts/package.py
```

กำหนด `CHROMIUM_PATH` หาก Chromium ไม่อยู่ที่ `/usr/bin/chromium` ชุดทดสอบเบราว์เซอร์รันโค้ดที่ build แล้วกับหน้าแชตจำลองออฟไลน์ ใช้ตัวนับจริงใน Web Worker และจำลอง API สำหรับ storage/messaging ของ Chrome ไม่ต้องล็อกอินและไม่ใช้โทเคน GPT

เบราว์เซอร์ในคลาวด์นี้ปิดการโหลด unpacked extensions ตามนโยบายเครื่อง จึงยังไม่ได้ยืนยันการติดตั้งส่วนเสริมจริงหรือทดสอบกับบัญชี ChatGPT การผ่านชุดทดสอบไม่ได้ยืนยันยอดโควตาของบัญชีหรือการทำงานกับหน้าเว็บทุกเวอร์ชัน

ไฟล์ส่วนเสริมที่พร้อมโหลดอยู่ใน `dist/` ส่วน ZIP และภาพหน้าจอจากการทดสอบอยู่ใน `artifacts/`
